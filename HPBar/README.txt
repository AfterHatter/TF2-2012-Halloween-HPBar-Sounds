TF2 Halloween Boss HP Bar & Sound (2012 Remaster)

This project recreates and remasters the 2012 Halloween Boss HP bar # Sounds for modern Team Fortress 2.
The original design has been fully redrawn and updated to work in casual matches and all modern HUDs.

Features:
- Completely redrawn 2012-style boss HP bar
- Old boss death and spawn sounds
- Works in casual matches
- Compatible with all HUDs
- Clean VGUI implementation

This repository contains the source files of my GameBanana release:
https://gamebanana.com/mods/385491
